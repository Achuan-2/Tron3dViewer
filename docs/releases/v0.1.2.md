Tron 3D viewer v0.1.2 修复了 PDF 标签裁切与外围留白问题，并将项目包名和启动命令统一为 `tron3dviewer`。

- **PDF 成图完整显示**：导出范围包含完整的 X/Y/Z 标题、刻度文字和线条，自动去除外围空白。
- **精确设置成图尺寸**：宽高包含坐标文字；调整任一尺寸、字号或线宽时，另一尺寸自动联动，保持当前视角下的三维图像比例。PDF 页面物理尺寸与设置值一致。
- **统一项目名称**：Python 包、启动命令、安装包、打包配置和文档统一使用 `tron3dviewer`。源码启动命令为 `uv run tron3dviewer`。
- **兼容旧 IMS 文件**：仍可读取旧版本保存的显示设置，新保存的设置使用新名称。
- **完善 IMS 空间校准**：保存时转换物理单位并保留空间原点，提高异常显示设置的读取容错。
- **修正跨平台打包路径**：统一 Windows/macOS 的启动脚本、图标和产物名称。

下载 `tron3dviewer-Windows-x86_64.exe`（Windows x64）或 `tron3dviewer-macOS-arm64.dmg`（macOS Apple Silicon）。`SHA256SUMS` 提供安装包校验值。
