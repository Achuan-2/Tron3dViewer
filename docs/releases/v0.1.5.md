Tron 3D viewer v0.1.5 新增“关于”对话框和软件引用信息，并完善了 Windows 安装包构建流程。

- **关于对话框**：集中展示软件版本、作者、GitHub 仓库、Zenodo DOI 和赞赏信息。
- **欢迎引用**：README 增加 Zenodo DOI 徽章和中英文引用说明，便于在科研文章中引用本软件。
- **Windows 安装包**：通过 GitHub Actions 自动构建带版本号的 Windows 安装程序。

下载 `tron3dviewer-0.1.5-Windows-x86_64-Setup.exe`（Windows x64）或 `tron3dviewer-0.1.5-macOS-arm64.dmg`（macOS Apple Silicon）。`SHA256SUMS` 提供安装包校验值。
