Tron 3D viewer v0.1.3 调整了 PDF 默认边框样式，并完善了发布产物与开源许可信息。

- **PDF 默认边框更精细**：Frame 默认线宽由 `1.0 pt` 调整为 `0.5 pt`，仍可在导出对话框中自定义。
- **安装包标明版本**：Windows 和 macOS 发布安装包的文件名增加版本号，便于区分和留存不同版本。
- **明确开源许可**：补充 AGPL-3.0-only 许可证文件及 Python 包许可元数据。

下载 `tron3dviewer-0.1.3-Windows-x86_64.exe`（Windows x64）或 `tron3dviewer-0.1.3-macOS-arm64.dmg`（macOS Apple Silicon）。`SHA256SUMS` 提供安装包校验值。
